# 🚢 Система мониторинга контейнеров на базе LoRaWAN

Система для автоматизированного мониторинга температуры и состояния контейнеров в реальном времени с использованием технологии LoRaWAN.

## 🎯 Цель проекта

Создать автоматизированную систему мониторинга температуры и состояния контейнера (открытие/закрытие), способную:
- Собирать данные с датчиков во время перевозки
- Передавать данные через сеть LoRaWAN
- Обрабатывать и хранить данные
- Уведомлять оператора при выходе за границы температур или открытия контейнера

## 🛠 Технологический стек

### Backend & Data Processing
- **Python** – основной язык программирования
- **Pandas** – для манипуляции и обработки данных
- **Flask** – веб-фреймворк для создания API и интерфейса
- **Requests** – для отправления и обработки HTTP запросов

### База данных
- **PostgreSQL** – основная база данных для хранения данных (планируется)
- **SQLite** – используется на этапе разработки

### Инфраструктура & IoT
- **Putty** – для подключения к базовой станции
- **LoRaWAN** – сеть передачи данных

### Уведомления
- **SMS API** – отправка уведомлений операторам
- **REST API** – интеграция с внешними системами

## 📡 Устройства LoRaWAN

### Базовое оборудование
1. **Базовая станция БС-2.2** - прием и передача данных
2. **Термологгер ТЛ-11** - мониторинг температуры
3. **Датчик SMART-HS0101** - мультисенсор (влажность/температура/открытие/ускорение)

### Расположение датчиков
- **Внутри контейнера**: ТЛ-11 - контроль температуры груза
- **Снаружи контейнера**: SMART-HS0101 - мониторинг внешних условий и состояния двери

## 🔄 Работа системы

### 1. Сбор данных
Датчики (ТЛ-11 и SMART-HS0101) устанавливаются внутри и снаружи контейнера для мониторинга:
- 🌡️ Температура (внутренняя/внешняя)
- 💧 Влажность
- 🚪 Состояние двери (открытие/закрытие)
- 📳 Уровень вибрации
- 🔋 Уровень заряда батареи
- 📶 Сила сигнала (RSSI)

### 2. Передача данных
- Данные передаются по сети **LoRaWAN** на базовую станцию **БС-2.2**
- Базовая станция обеспечивает прием сигналов от всех устройств в зоне покрытия

### 3. Обработка и хранение
- Данные через интерфейс базовой станции передаются на сервер
- Обработка данных с помощью **Python** и **Pandas**
- Сохранение в базу данных **PostgreSQL** для анализа и отчетности

### 4. Мониторинг и уведомления
- **Веб-приложение на Flask** предоставляет интерфейс для операторов
- Отображение текущих параметров контейнера в реальном времени
- **Автоматические уведомления** при:
  - Превышении допустимой температуры
  - Открытии контейнера
  - Высокой влажности
  - Сильной вибрации
  - Низком заряде батареи

### 5. Обратная связь и управление
- Операторы могут управлять настройками системы через веб-интерфейс
- Генерация отчетов по перевозкам
- Полный контроль над состоянием грузов во время перевозки
